# Google searches for the volume lane (copy one into Google, scroll, save the page)

How: paste a line into Google, scroll through 3-5 pages, then on each page press Ctrl+A, Ctrl+C
and paste into one text file (for example `google.txt` in the repo folder). Then:

```bash
python run.py import-google google.txt --approve-spend
```
